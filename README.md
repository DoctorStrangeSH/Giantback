# Giantback · Город на спине

Откройте Giantback.rbxlx в Roblox Studio и нажмите Play. Исходники открыты для редактирования в этом репозитории. Команда `python build.py` пересобирает место.

## Первый маршрут

1. Сойдите со спины Мохоспина по мостику. В конце тропы познакомьтесь с лисёнком.
2. На тропе попросите спутника найти семя. В альбоме можно менять спутников.
3. Вернитесь на спину и используйте штурвал. В Лунной роще найдите моль.
4. Подойдите с молью к клумбе возле дома, чтобы вырастить личный лунный цветок.
5. Вернитесь в Солнечную рощу с лисёнком. Он найдёт у коряги сухие ветви. На площадке рядом со штурвалом соберите из них фонарь.
6. Позовите моль из альбома и ещё раз взаимодействуйте с фонарём. Он загорится и будет путешествовать вместе с домом. Постройка и её свет видны владельцу сада.

Личная метка ведёт к следующей цели. Если нужная роща на другом берегу, она укажет на штурвал. Если Мохоспин уплыл без вас, колокольчик поможет вернуться на борт.

Гигант общий для сервера. Коллекция и сад личные. Колокольчик на каждом берегу возвращает игрока домой. В Studio прогресс действует в пределах тестового запуска. В опубликованной игре сервер сохраняет открытия через DataStore.

## Границы первой версии

Два спутника, один общий гигант, две стоянки, готовый дом, выращиваемый цветок и первая постройка на фиксированной площадке. Свободное размещение построек и рост гиганта из детёныша запланированы для следующих версий.
