# Giantback · Город на спине

**Giantback** — уютное приключение о живом гиганте, который путешествует между сказочными берегами. Игрок исследует мир, знакомится с необычными спутниками, использует их способности и постепенно превращает сад на спине Мохоспина в собственный дом.

## Запуск

1. В корне репозитория выполните python build.py.
2. Откройте пересобранный Giantback.rbxlx в Roblox Studio.
3. Нажмите **Play** в Roblox Studio.

build.py собирает place из исходников и встраивает игровые скрипты. Внешние плагины и скачанные модели для базовой версии не нужны.

## Первый маршрут

1. Сойдите со спины Мохоспина по мостику. В конце тропы познакомьтесь с лисёнком-корешком.
2. Позовите лисёнка и попросите его поискать семя на тропе.
3. Вернитесь на спину и используйте штурвал. В Лунной роще познакомьтесь с лунной молью.
4. Позовите моль у клумбы возле дома, чтобы вырастить личный лунный цветок.
5. Вернитесь в Солнечную рощу с лисёнком. Он найдёт у коряги сухие ветви.
6. Постройте садовый фонарь на площадке возле штурвала, затем позовите моль и зажгите его.

Личная метка ведёт к следующей цели. Если нужная роща находится на другом берегу, она укажет на штурвал. Если Мохоспин уплыл без игрока, береговой колокольчик поможет вернуться на борт.

## Игровые опоры

- **Живой дом:** общий для сервера Мохоспин путешествует между стоянками.
- **Личная история:** коллекция, сад и прогресс принадлежат конкретному игроку.
- **Спутники с пользой:** питомцы не просто следуют за игроком — их способности нужны для исследования и строительства.
- **Открытия:** берега отличаются атмосферой, растениями и секретами.
- **Уютная персонализация:** сад и дом постепенно наполняются вещами, которые игрок получил своими действиями.

## Границы текущей версии

Первая игровая вертикаль: один общий гигант, две стоянки, два спутника, личный лунный цветок, первая постройка и законченный маршрут знакомства с миром. Свободное размещение построек, рост гиганта из детёныша, дополнительные биомы и новые спутники остаются расширениями после проверки базового цикла.

## Сохранения

В Studio прогресс действует в пределах тестового запуска. В опубликованной игре коллекция сохраняется через DataStore. Для публикации необходимо проверить настройки API Services и тест сохранения на отдельном опубликованном месте.
