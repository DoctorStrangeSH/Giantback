# Giantback — Roadmap

Источник требований: PROJECT_SPEC.md. Новые идеи не расширяют объём версии 1.0 автоматически.

**Статусы:** [x] реализовано в исходниках; [ ] не реализовано или не проверено. Код, прошедший автоматическую сборку, всё равно требует проверки в Roblox Studio.

## Этап 0. Стабилизация текущего прототипа

### Реализовано в исходниках
- [x] Базовый place и сборка через build.py.
- [x] Мохоспин, дом, Солнечная и Лунная рощи.
- [x] Путешествие между двумя стоянками.
- [x] Лисёнок-корешок и лунная моль.
- [x] Альбом спутников и переключение активного питомца.
- [x] Семя, лунный цветок, ветви и садовый фонарь.
- [x] Локальное скрытие дикого питомца после знакомства — исправление дубликата.
- [x] Защита повторного знакомства с уже собранным питомцем.
- [x] Процедурная idle/follow-анимация лисёнка и анимация крыльев моли.
- [x] Серверные узлы сбора солнечных и лунных лепестков с персональным состоянием каждого игрока.
- [x] Серверный инвентарь, персональный cooldown и сохранение уникальных находок в профиле.
- [x] Счётчики ресурсов встроены в единую панель коллекции.
- [x] Idle-анимация диких существ в местах знакомства.
- [x] Визуальная основа Cozy Fantasy Adventure.
- [x] Автоматическая сборка и XML-валидация place в GitHub Actions.

### Требуется проверка
- [ ] Проверить, что после знакомства виден только один лисёнок.
- [ ] Проверить, что другой игрок всё ещё может найти дикого лисёнка.
- [ ] Проверить движения лап, хвоста и ушей лисёнка.
- [ ] Проверить парение и крылья лунной моли.
- [ ] Проверить анимации при смене питомца, респавне и повторном входе.
- [ ] Проверить сбор ресурса: один игрок подбирает цветок, он исчезает только у него, второй игрок всё ещё видит и может собрать свой ресурс.
- [ ] Проверить, что повторное срабатывание prompt до окончания персонального cooldown не начисляет предмет.
- [ ] Проверить восстановление цветка ровно по персональному таймеру в 300 секунд.
- [ ] Проверить, что персональный cooldown и инвентарь сохраняются после выхода и повторного входа.
- [ ] Проверить, что уникальная находка навсегда скрывается только для её владельца.
- [ ] Проверить изоляцию городов двух игроков: каждый видит только свой дом и грядки.
- [ ] Проверить, что игрок не может активировать грядку другого владельца.
- [ ] Проверить, что личный дом и ферма движутся вместе с Мохоспином при путешествии.
- [ ] Проверить посадку моркови, рост 180 секунд и сбор созревшего урожая.
- [ ] Проверить сохранение незрелого урожая и продолжение роста после повторного входа.
- [ ] Проверить панель фермы на мобильном экране.
- [ ] Проверить весь маршрут прототипа в Roblox Studio.
- [ ] Проверить производительность визуального слоя.
