# Import-ready models

Place only reviewed exports here, with a per-asset folder and metadata file.

Suggested layout: `models/companions/fox/`, `models/companions/moth/`, `models/environment/home_cottage/`.

Do not store raw source OBJ/MTL here; those belong in `source_models/`. Do not mark a model production-ready until Blender validation and Roblox Studio import/scale/pivot/collision review are complete.
