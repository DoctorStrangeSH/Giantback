# Giantback — Roblox Studio: первый полноценный плейтест

**Статус:** инструкция и диагностика подготовлены; успешный GitHub Actions не является подтверждением игрового плейтеста. Ни один импортированный MeshPart пока не считается автоматически утверждённым.

## Получить актуальную игру

1. Открой [GitHub Actions](https://github.com/DoctorStrangeSH/Giantback/actions/workflows/validate-place.yml) и выбери **последний успешный запуск ветки `main`**. С 23 ноября 2026 игровые исходники включены в `main` через [PR #8](https://github.com/DoctorStrangeSH/Giantback/pull/8); старые PR #1/#7 не являются источником актуальной сборки.
2. Внизу запуска скачай артефакт `Giantback-visual-build`. Внутри — `Giantback.rbxlx` и исходные ресурсы. Не путай файл сборки с исходными OBJ.
3. Распакуй архив. Открой `Giantback.rbxlx` через **Roblox Studio → File → Open from File**.
4. Если Roblox Studio предлагает сохранить копию, используй отдельную тестовую версию/файл. **Не публикуй поверх рабочей игры до приёмки.**

## Быстрая диагностика (без изменения мира)

Скрипт: `tools/roblox/studio_playtest_preflight.luau` (в архиве сборки и в GitHub).

1. В Roblox Studio открой **View → Output** и **View → Command Bar**.
2. **В режиме Edit** вставь весь текст скрипта в **Command Bar** и выполни. Он покажет `PASS`, `FAIL`, `REVIEW` и `PENDING` для скриптов, модулей, мира и резервных моделей питомцев.
3. Нажми **Play**, дождись появления персонажа. Переключи Command Bar в **Server** context (если Studio предлагает выбор контекста) и выполни тот же скрипт ещё раз.
4. Убедись, что в Output есть `SUMMARY` и отметки `PlayerIslands`, `HomeIsland_<UserId>`, `HomeSpawn`, `Ready`. Если `Ready` ещё не установлен, дай игре закончить загрузку и повтори проверку.
5. `PENDING` не считается успехом: это означает, что режим Edit или текущая конфигурация не позволяет подтвердить пункт. `REVIEW` означает обязательную ручную проверку.

Скрипт только читает структуру. Он **не включает** готовность ассетов, **не меняет** DataStore, **не сохраняет** и **не публикует** игру.

## Игровой маршрут приёмки

Отмечай каждый пункт только после проверки в самой Studio:

- [ ] **Первое появление:** персонаж появляется на собственном домашнем острове, видит понятную первую цель, нет критических ошибок в Output
- [ ] **Сбор ресурсов:** получить дерево и камень, увидеть индикаторы удара и изменение запасов; ресурс восстанавливается с правильным временем, уникальный ресурс не дублируется
- [ ] **Мост:** восстановить стартовый мост за 5 дерева и 3 камня, перейти в общую рощу, вернуться
- [ ] **Строительство и ферма:** размещение и действие понятны без инструкции; окна UI закрываются с первого раза
- [ ] **Питомцы:** найти лису/моль, приручить, экипировать, погладить с подсказки, проверить следование, анимацию, отдых и эффекты
- [ ] **Добыча и бой:** протестировать инструмент, уклонение, базовую атаку и предупреждения противника
- [ ] **Экспедиция:** проверить доступность общего мира и как минимум одного исследовательского маршрута
- [ ] **Перезаход:** выйти из Play и запустить снова; проверить сохранение открытий, построек и питомцев (зависит от разрешённых Studio DataStore API)
- [ ] **Два игрока:** Test → Server & Clients (2 клиента); домашние острова не пересекаются, общий мир виден обоим, владение питомцами и награды не смешиваются
- [ ] **Мобильная проверка:** Device Emulator с узким экраном; доступны основные кнопки, текст и закрытие окон, управление не перекрывается

## 3D-модели — отдельный gate

Для `FoxCompanion` и `MothCompanion` сначала сделай импорт через 3D Importer, затем используй `tools/roblox/organize_imported_assets.luau` (начальный режим **DRY RUN**), затем `tools/roblox/inspect_companion_imports.luau` (только диагностика). Детали — в [ASSET_IMPORT.md](ASSET_IMPORT.md).

**Не ставь** `GiantbackImportStatus = Approved`, `GiantbackRuntimeReady = true` или `GiantbackProceduralAnimationCompatible = true` только по результату скрипта. Нужны ручная проверка силуэта, масштаба, pivot, независимых крыльев/хвоста, коллизий, сетевой и мобильной работы. Пока этого нет, рабочие заготовки остаются в игре.
